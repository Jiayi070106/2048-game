# 2048 小游戏
一个使用原生 JavaScript 实现的 2048 网页游戏。支持键盘方向键、分数统计、最高分记录、游戏进度保存。
## 功能特效
- ✅ 键盘方向键（↑ ↓ ← →）控制方块移动
- ✅ 相同数字方块合并，分数累加
- ✅ 游戏胜利/失败检测（胜利目标：2048）
- ✅ 当前分数 & 历史最高分（自动保存在浏览器中）
- ✅ 游戏进度自动保存（刷新页面后恢复棋盘）
- ✅ 方块滑动动画 + 入场/合并弹出动画
- ✅ New Game 重置游戏
- ✅ 胜利/失败蒙层，点击按钮重新开始
## 技术栈
- 原生 JavaScript (ES Module)
- CSS3 (动画、过渡、Flex布局)
- HTML5
- 浏览器本地存储 (localStorage)
